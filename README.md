# Misokuhle Financial Services — Client Version 1

Built from the supplied Misokuhle design.

## Workflow
Website → 40% calculator → Online application → Email notification through FormSubmit + WhatsApp → Manual processing

## Included
- Original supplied design/branding
- 40% flat-interest calculator
- R1,000–R3,000 calculator limit based on supplied flyer
- Online application page
- Application reference number
- Direct WhatsApp follow-up to 081 435 7440
- No database
- No admin dashboard
- No document uploads

## Email
The application form uses FormSubmit's AJAX endpoint to send application notifications to Misokuhlefinancials@gmail.com. No Gmail password is stored in the website. On the first real/test submission, FormSubmit may send an activation/confirmation email to the business mailbox; the form must be activated before normal submissions are delivered. The website should be tested on the live GitHub Pages URL, not by opening the HTML file directly.

## Important
Confirm the client's exact 40% charging method, fees, repayment terms, eligibility rules and applicable South African financial-services compliance requirements before publishing the calculator or accepting real applications.
